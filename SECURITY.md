# Signaler une faille

Une faille dans l'Observatoire post-quantique (observatoire.mesa.black, son
administration, le service handshake.mesa.black) se signale en privé, depuis
l'onglet **Security** de ce dépôt : « Report a vulnerability ». Le signalement
n'est visible que de nous.

Merci d'y décrire ce qui se passe, comment le reproduire, et ce que vous avez pu
voir ou modifier. Nous répondons sous sept jours, nous disons ce que nous
corrigeons et quand, et nous vous citons si vous le souhaitez.

Restez sur vos propres données : pas de déni de service, pas de lecture ni de
modification des données d'autrui, pas d'envoi de courriels à des adresses qui
ne sont pas les vôtres.
